# Security Policy

## Supported versions

Security fixes are intended for the latest published release. Older versions may not receive patches.

## Reporting a vulnerability

Do not publish exploitable vulnerability details in a public issue. Use GitHub's private vulnerability reporting feature for this repository, if enabled. If private reporting is unavailable, contact the repository maintainer through the contact options on the GitHub profile and request a private channel.

Include:
- A concise description and impact.
- Reproduction steps or a proof of concept.
- Affected version, distribution and environment.
- Any suggested mitigation.

Do not include real credentials, private source code or personal data in a report.
